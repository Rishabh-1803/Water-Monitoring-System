Abstract—

Efficient water management is essential in agricultural and environmental applications, where improper irrigation leads to water wastage and reduced yield. Conventional manual monitoring is labour-intensive, offers no record of what was applied and when, and cannot respond to changing conditions. This paper presents the design and implementation of an IoT-based water monitoring and automated irrigation system built on an ESP32-S3 microcontroller. The device interfaces a resistive soil-moisture probe and a DHT11 temperature and humidity sensor, and actuates a 12 V solenoid valve through a 5 V relay module. Analog moisture measurements are conditioned using an eight-sample trimmed-mean filter and mapped to a percentage through a two-point calibration held in non-volatile storage, and both sensor channels are monitored for open-circuit and communication faults so that a failed sensor suppresses automatic operation rather than driving it.

Irrigation is gated by a multi-condition decision rule: watering proceeds only inside a configured time window, when the three-hour rainfall forecast obtained from a public weather service is below a set threshold, when no sensor fault is present, and when measured moisture falls below the target. A hysteresis band prevents relay chatter around the setpoint, and an independent latching timer closes the valve and disables automatic operation if it remains open beyond a maximum permitted duration, so that no single faulty measurement can cause sustained water loss. The system fails closed in every fault path, including power-on and loss of network connectivity.

The firmware additionally implements a local operator interface and a telemetry path. An embedded web dashboard and JSON API served over HTTP provide live readings, threshold and schedule configuration, sensor calibration, twenty-four-hour trend visualisation, CSV export, diagnostics and over-the-air firmware update. The local interface is protected by HTTP Basic Authentication, per-address request rate limiting, a required custom request header to defeat cross-site request forgery, and an append-only access log stored on an on-device LittleFS filesystem. Configuration and calibration persist in non-volatile storage so that full operating state is recovered after power loss without network access. Measurements are published to an MQTT broker and to an InfluxDB v2 time-series database, and eleven classes of operational event generate alerts to a messaging service with per-class rate limiting. Wireless credentials are provisioned at runtime through a captive portal rather than compiled into the firmware. The resulting system demonstrates that closed-loop irrigation control, secure local administration and cloud telemetry can be implemented together on a single low-cost microcontroller, and is presented as a practical platform for teaching embedded systems, IoT integration and device security, with identified scope for further work in transport encryption of the local interface, real-time task partitioning of the control loop, and closed-loop verification of flow.

**Index Terms—**ESP32-S3, Internet of Things, Smart Irrigation, Soil Moisture Sensing, Embedded Systems, Automation, Sensor Fault Detection, MQTT, Time-Series Telemetry, Embedded Device Security.
